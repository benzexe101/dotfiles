# dotfiles

Neovim, Hyprland, and kanata config.

Neovim is set up for C++, Rust, Python, TypeScript, and Java, with LSP,
completion, formatting, and a debugger. Works on Linux and Windows.

## Homelab and Troubleshooting

The `docs/runbooks/` directory contains documentation from my personal Linux homelab and system administration projects.

Topics include:

- UEFI Secure Boot configuration and recovery on a Windows/Linux dual-boot system
- Nextcloud connectivity troubleshooting involving DNS and TLS certificates
- RTSP camera integration and troubleshooting using Linux and Python
- Terminal-based development workflows

These runbooks document technical problems, troubleshooting methods, resolutions, and lessons learned. Network information and identifying details have been anonymized.
